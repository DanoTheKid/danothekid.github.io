# Entrada a la copia institucional de CIVICA

La ruta https://danothekid.github.io/civica/ abre la copia independiente del sitio institucional, alojada en Sites:

https://civica-institucional-danothekid.vivaciousdonkey1.chatgpt.site/

La copia conserva ocho páginas HTML, imágenes, estilos, fuentes, cuatro documentos PDF y diez archivos CSV del sitio público de origen: https://ingenieria.bogota.unal.edu.co/civica/.

GitHub Pages publica esta entrada con una redirección HTML y un enlace visible de respaldo. Sites aloja el contenido conservado. El nombre github.io pertenece a GitHub Pages; la navegación cambia a la dirección de Sites.

Los visores y el simulador siguen en un servidor privado. Los videos de YouTube, podcasts de Spotify y publicaciones externas dependen de sus proveedores. El catálogo de la copia explica su alcance y ofrece los documentos descargables.
